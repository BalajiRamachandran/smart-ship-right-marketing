# Illustrations (unDraw)

This folder holds **context-relevant SVGs** used alongside the custom sketches across the marketing site. The current assets are from [unDraw](https://undraw.co) (MIT license), downloaded and saved locally for warehouse/app context.

## Included files (unDraw source)

| Filename       | unDraw illustration        | Used for                          |
|----------------|----------------------------|------------------------------------|
| `hero.svg`     | Deliveries                 | Home hero section                  |
| `warehouse.svg`| Logistics                  | Warehouse sections                |
| `inventory.svg`| Spreadsheet                | Inventory management              |
| `picking.svg`  | Add tasks                  | Picking / task lists               |
| `order.svg`    | Delivery location          | Order / delivery                   |
| `dashboard.svg`| Data reports               | Dashboard / analytics             |
| `integration.svg` | Cloud sync              | Integrations (Shopify, ShipStation)|

These were fetched from `cdn.undraw.co` and saved with the filenames above so the app renders them in the right places. If the SVG files are missing (e.g. after reverting changes), re-download the matching unDraw illustrations and save them here with the exact filenames in the table.

## Replacing with Storyset (optional)

To use [Storyset](https://storyset.com) illustrations instead:

1. Go to [storyset.com](https://storyset.com), pick a style, and search for themes that match (e.g. Delivery, Warehouse, Inventory, Dashboard, Integration).
2. Customize and download as **SVG**, then save into this folder using the **exact filenames** in the table above (e.g. `hero.svg`, `warehouse.svg`).
3. Storyset requires attribution; add “Illustrations by Storyset” in the footer if you switch.

## Attribution

The app footer credits **unDraw** for the current illustrations. If you replace them with Storyset assets, update the footer to credit Storyset instead.
